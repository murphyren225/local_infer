# Roadmap

## v0.1 — 骨架能转（当前）

- [x] OpenAI 兼容网关：路由、缓存、升级、指标、流式透传
- [x] 单元测试 21 例 + 路由评测 28 例，CI 守门
- [x] 首启自动调参（4 个显存档位）
- [x] docker-compose 一键部署（双 vLLM 共卡）
- [ ] **RTX 4090 真机端到端验证**：显存分片参数校准、吞吐/延迟基线（下一步的重点）

## v0.2 — 可运营

- [ ] Prometheus 指标导出 + Grafana 面板（替代进程内统计）
- [ ] 请求日志落盘（脱敏），构成误路由样本回流管道
- [ ] API key 鉴权与简单限流
- [ ] 答案质量评测：对评测集在双车道跑真实推理，LLM-judge 打分，给"哪些任务小模型真的够用"提供数据

## v0.3 — 更聪明的路由

- [ ] Tier-2 路由：4B 对灰区请求做难度自评（前提：v0.2 的样本回流已积累标注）
- [ ] 语义缓存（embedding 相似度，可选开启）
- [ ] 混合部署：large lane 可指向云端 API，本地 32B 与云端之间再加一层升级

## v0.4 — 产品化

- [ ] Web 管理台：路由分布、省钱账单、误路由标注界面
- [ ] 多硬件档位实测数据（3090 / 4080 / 4070 / A6000）
- [ ] apt/一键脚本发布渠道

## 原则

每个版本只有一个主题；真机验证优先于新功能；没有评测数据支撑的"智能"功能不合并。
