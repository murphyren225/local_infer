# 路线图

## 已完成

- 单机全栈（vLLM 双池 + Switchyard + Pi + 控制台）在 RTX 4090D 真机验证
- 故障切换与分段自愈（破坏性演练通过）
- Mac Hub + 远端 GPU 双设备联动（SSH 隧道）
- 按层分包重构；控制平面单元测试；注册表驱动的热插拔（init / link-gpu 已验证）
- 拆成两套系统：`cluster/`（推理端）与 `client/`（Pi 端，每人一套：Pi 接线 + 个人网页前端）

## 进行中 / 待做

- 通用 `join`：已实现，待局域网双机验证
- Pi 端托管模式：Hub 上按人起 Pi 会话（容器隔离），浏览器零安装；之后再做本机一键安装包（Node + Pi + 便携 Python）
- 池内多副本负载均衡层（sgl-router 或 nginx）
- 网关 `--reload` 热加载替代重启
- 设备自动发现与网页批准
- 过载保护（队列上限 + 429）与租户配额
- Prometheus / Grafana：容量、成本、硬件三类指标的时间序列与告警
- 长上下文池（128GB 主机 + 300B MoE）preset 与真机校准
- 云端预算上限与审批
- 检索增强：接入客户内部文档

## 原则

每个版本一个主题；真机验证优先于新功能；没有实测数据支撑的能力不写进文档。
